# Dataset

`used_cars.csv` is an illustrative synthetic dataset created for this project. It has 1,400 rows and these columns:

- `make`, `model`: car make and model
- `year`: model year
- `km_driven`: kilometres driven
- `fuel`: fuel type
- `transmission`: manual or automatic
- `owner`: owner count category
- `engine_cc`: engine capacity
- `selling_price`: target price in INR

A small number of cells are intentionally missing or formatted as text so the cleaning pipeline has something to handle. Do not describe it as real market data.
